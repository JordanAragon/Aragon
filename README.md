Introducción
El presente informe describe las herramientas, lenguajes y elementos técnicos empleados en el desarrollo de la actividad "Página de Servicios para una Agencia Digital", una landing page construida con HTML5, CSS3 y el framework Bootstrap, complementada con Media Queries para su adaptación a distintos tamaños de pantalla. El documento explica el propósito de cada herramienta dentro del proyecto y la forma en que se integraron para cumplir con los objetivos de la actividad.
HTML5: Estructura y Semántica
HTML5 se utilizó como base estructural del sitio. Se emplearon etiquetas semánticas como header, nav, main, section, article y footer, las cuales permiten organizar el contenido de forma lógica y mejoran la accesibilidad e interpretación del documento por parte de navegadores y lectores de pantalla. La jerarquía de encabezados (h1 a h3) se usó para establecer el orden de importancia de la información presentada en cada sección.
La navegación principal se construyó con una lista no ordenada (ul/li) cuyos enlaces (a) apuntan a las distintas secciones internas de la página mediante anclas (#servicios, #planes, #portafolio, #contacto), además de enlaces externos hacia las redes del autor en el pie de página. Este enfoque evita el uso de scripts adicionales para la navegación básica y mantiene la página accesible incluso sin JavaScript.
Representación de Datos: Tabla de Precios
Para mostrar los planes y tarifas de los servicios ofrecidos se utilizó la etiqueta table, acompañada de un caption descriptivo que identifica el propósito de la tabla. Los encabezados de columna se definieron dentro de thead usando th con el atributo scope="col", mientras que el contenido de cada fila se organizó en tbody mediante tr y td, empleando también th con scope="row" para identificar el nombre de cada servicio. Esta estructura mejora la lectura de la tabla por parte de tecnologías de asistencia y ordena la información de forma clara para el usuario final.
Formularios y Accesibilidad
La sección de contacto se implementó mediante la etiqueta form, con los atributos action y method definidos para el envío de la información. Se incluyeron distintos tipos de campo: input tipo text para el nombre, input tipo email para el correo electrónico, un conjunto de input tipo radio para seleccionar el servicio de interés, y un textarea para el mensaje del cliente. Los campos se agruparon mediante fieldset y legend, lo que organiza visual y semánticamente la información solicitada.
Cada campo del formulario cuenta con una etiqueta label asociada mediante los atributos for e id, lo cual es una práctica indispensable de accesibilidad, ya que permite que lectores de pantalla anuncien correctamente el propósito de cada campo y que el usuario pueda hacer clic sobre la etiqueta para enfocar el campo correspondiente. Adicionalmente, se usó el atributo required en los campos obligatorios para realizar una validación básica en el navegador antes del envío del formulario.
CSS3: Estilos y Modelo de Caja
El diseño visual del sitio se desarrolló en una hoja de estilos externa (style.css). Se aplicó la propiedad box-sizing: border-box de forma global para que el padding y el borde de los elementos no alteraran su ancho total, facilitando el control del modelo de caja (width, padding, border y margin) en cada componente.
Se definieron colores de fondo (background-color) tanto a nivel general del documento como en secciones específicas, con el fin de diferenciar visualmente los distintos bloques de contenido (secciones claras y oscuras). También se trabajaron transiciones simples, bordes redondeados y sombras sutiles para dar una apariencia más profesional a las tarjetas de servicios y del portafolio.
Bootstrap: Sistema de Rejilla y Diseño Responsivo
Para acelerar la maquetación y garantizar un comportamiento responsivo desde un primer nivel, se integró el framework Bootstrap mediante su CDN. Se utilizó el sistema de rejilla a través de las clases container, row y las columnas col-sm-6 y col-md-4, lo que permite que las tarjetas de servicios y del portafolio se reorganicen automáticamente según el ancho de la pantalla, apilándose en dispositivos móviles y distribuyéndose en varias columnas en pantallas medianas y grandes.
Media Queries: Ajustes Personalizados
Aunque Bootstrap resuelve gran parte del comportamiento responsivo, se definieron Media Queries adicionales en el archivo CSS para ajustes específicos no cubiertos por el framework. Se establecieron dos puntos de quiebre (breakpoints), en 768px y 576px, en los cuales se modifican tamaños de fuente, espaciados internos y la disposición de algunos elementos de navegación, con el objetivo de optimizar la lectura y la experiencia de uso en tablets y celulares.
Estructura del Proyecto
El proyecto se organizó en tres componentes principales: el archivo index.html, que contiene la estructura y el contenido del sitio; la carpeta css, con la hoja de estilos style.css; y la carpeta img, que almacena las imágenes utilizadas en la sección de portafolio. Esta organización facilita el mantenimiento del código, la separación entre estructura y presentación, y su despliegue en un servicio de alojamiento estático.
Publicación con GitHub Pages
Para la entrega del proyecto, el código se aloja en un repositorio de GitHub y se publica mediante GitHub Pages, un servicio gratuito que permite servir archivos estáticos (HTML, CSS e imágenes) directamente desde el repositorio, sin necesidad de un servidor propio. Este mecanismo facilita compartir una vista en línea de la landing page mediante un enlace público, además de mantener un historial de cambios del código a través de control de versiones con Git.
Buenas Prácticas de Diseño y Experiencia de Usuario
Además de los requisitos técnicos, se buscó que la página tuviera una experiencia de usuario coherente: una navegación fija en la parte superior para facilitar el acceso a las distintas secciones, un contraste adecuado entre texto y fondo, botones con estados de interacción (hover) claramente diferenciados, y un espaciado consistente entre secciones que evita que el contenido se vea saturado. Estas decisiones de diseño, aunque no dependen de una sola herramienta, se apoyan en el uso conjunto de CSS y de las utilidades de Bootstrap descritas anteriormente.
Conclusiones
La combinación de HTML5, CSS3, Bootstrap y Media Queries permitió construir una landing page funcional, accesible y adaptable a distintos dispositivos, cumpliendo con los criterios de semántica, modelo de caja y diseño responsivo solicitados en la actividad. El uso de un framework como Bootstrap, junto con ajustes personalizados mediante Media Queries, demuestra cómo estas herramientas se complementan para lograr un desarrollo web más eficiente sin sacrificar el control sobre el diseño final.
